# @fingerly/core

The platform-independent kernel of the Fingerly SDKs: scheduling, consent,
transport and the local verdicts. It has no sources of its own.

You almost certainly want [`@fingerly/web-js`](https://www.npmjs.com/package/@fingerly/web-js)
instead, or one of the framework bindings built on it. They install this
package for you.

Documentation: [docs.fingerly.io](https://docs.fingerly.io/docs/sdks/javascript)
